# Roadmap and Blocked Items

## External launch blockers

- Target production/staging host and deployment access.
- Target PostgreSQL `DATABASE_URL` and Alembic head proof.
- Secret-manager, CORS, HTTPS, storage, retention, and rotation evidence.
- API and worker process/heartbeat evidence.
- Backup and restore rehearsal plus reconciliation results.
- Edge/proxy/CDN/WAF throttling evidence.
- Real non-technical user walkthrough and manual keyboard/zoom/screen-reader QA.
- Acceptance owner, date, accepted risks, and launch decision.

## Provider roadmap

Official publishing is only a future candidate where a provider offers and approves an API. Each adapter requires credentials, sandbox create/read/update/delete proof, idempotency, quota handling, audit events, ambiguous-outcome reconciliation, cleanup, and policy acceptance before it can replace assisted posting.

## Deliberate non-goals

Teams/workspaces/billing are not part of the personal-account product and have no visible placeholder UI. External email/push notifications are not required for the current local-first action center.
